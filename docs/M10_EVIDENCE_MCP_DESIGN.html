“근거가 있는 답변 재료”로 바꾸기

이 문서는 M10 설계의 확정본입니다. M9가 찾은 Knowledge에 실제 Jira Evidence를 붙이고 Agent가 MCP로 안전하게 사용할 수 있게 하는 구조를 설명합니다. 이 설계는 이후 구현과 실제 Real-run까지 모두 PASS했습니다.

DESIGN FROZEN · IMPLEMENTATION PASS · REAL-RUN PASS · M10 DONE
최종 검증: tool_count 2, search_result_count 3, evidence_count 6, warning_count 0, path_leak_count 0, issue_lookup_ok true, failure_count 0, M10_REAL_RUN = PASS. 자세한 해설은 M10 Completion을 참조합니다.

1. 한 문장 역할

M10 = “이 Knowledge가 왜 맞는지 실제 Jira 근거를 붙여 Agent에게 주는 단계”
M9 "이 Knowledge가 질문과 비슷합니다." ↓ M10 "그 Knowledge의 실제 근거는 이 Jira 설명/댓글/관계입니다." ↓ Agent "그 근거를 바탕으로 최종 답변하겠습니다."

2. M9와 M10의 차이

M9 · 검색

질문과 가까운 Knowledge Top-3를 FAISS에서 찾습니다.

M10 · 근거

ki_ → ke_ → source로 실제 Jira Evidence를 복원합니다.

Agent · 답변

Knowledge + Evidence를 읽고 최종 자연어 답변을 만듭니다.

FAISS는 Jira 원문을 직접 검색하지 않습니다. FAISS는 Knowledge vector를 찾고 원문은 SQLite에서 복원합니다.

3. 전체 연결

사용자 질문 ↓ BGE-M3 query embedding ↓ M9 FAISS Top-3 rank + score + emb_ + ki_ ↓ M10 active/accepted 확인 ↓ ki_ Knowledge statement ↓ ke_ Evidence refs ↓ summary / description / comment / attachment / relationship / custom_field ↓ Evidence Package ↓ MCP Agent / LLM
