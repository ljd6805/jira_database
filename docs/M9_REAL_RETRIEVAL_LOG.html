3. 무엇을 재실행에서 비교하나?

필수 동일 retrieval_contract_hash (rc_) faiss_index_id (fi_) source_embedding_artifact_sha256 mapping_sha256 참고 faiss_binary_sha256

rc_는 검색 계약, fi_는 source embedding snapshot + index build profile의 logical identity입니다. 같은 source/contract라면 반드시 같아야 합니다.
