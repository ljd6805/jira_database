2. 현재 D8의 핵심 제안

COMPLETED = Discovery 성공 + 모든 visible Project Source window Source Commit 완료 + 필요한 NEW/CHANGED Publish 모두 완료 또는 not_required PARTIAL = durable한 성공 결과가 하나 이상 있음 + Source 또는 Publish에 미완료/실패가 남음 FAILED = Discovery를 신뢰할 수 없거나 + 처리해야 할 Source 범위에서 durable progress를 하나도 만들지 못함 UNAVAILABLE Project = 실패가 아니라 이번 Source Sync에서 skip = 기존 Knowledge Retrieval 유지
현재 MVP와 차이: 기존 Collector는 하나라도 실패하면 모두 partial로 집계합니다. 운영 Sync에서는 “일부 성공”과 “신뢰 가능한 진행 없음”을 구분하기 위해 failed를 별도로 둡니다.
