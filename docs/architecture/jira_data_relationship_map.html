현재 설계 기준

  • RAW는 최종 사실 기준이며 파생 계층은 재생성 가능해야 합니다.
  • Issue Version은 source_hash가 바뀔 때만 새로 생성합니다.
  • Knowledge는 검색용 의미 압축이며 사실 원장이 아닙니다.
  • Historical Knowledge는 DB에 보존하지만 기본 RAG/FAISS에서는 제외합니다.
  • Active Knowledge만 기본 Retrieval corpus에 포함합니다.
  • Evidence는 exact evidence_ref를 보존하고 Source로 round-trip 해야 합니다.
  • Review는 모든 Attempt와 historical defect를 감사 가능하게 보존합니다.
  • M6는 Logical Schema 단계이며 SQLite DDL은 M7에서 구현합니다.
