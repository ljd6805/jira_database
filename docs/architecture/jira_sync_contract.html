Jira Source Lifecycle ≠ Knowledge Lifecycle

D7 · SOURCE_COMMITTED ≠ PUBLISHED

FIXED · PHYSICAL LOOP BOUNDARY

Loop A · SOURCE_COMMITTED

Source 산출물, semantic hash/classification, durable Work Item이 안전하고 Project Source window 책임이 완료된 상태.

Loop B · PUBLISHED

Knowledge/Evidence, Embedding, FAISS/Mapping이 검증되고 실제 Retrieval active view가 전환된 상태.

Loop B 소비 조건
SOURCE_COMMITTED + durable Work Item + Source Ready Gate open last_source_committed_run_id = last_observed_source_run_id

Candidate 단계에서 Work Item row를 먼저 저장해도 Project Source Commit 전에는 Processing할 수 없습니다.

Source Head V2 Published Head V1 → 정상 eventual-consistency 구간 → 사용자 Retrieval = V1 → V2 actual Publish 후 Published Head = V2

Half-Publish는 금지합니다.
