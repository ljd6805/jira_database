HISTORICAL DECISION · REVISED BY TWO-LOOP

D8의 “단일 Sync Run 상태”는
현재 2-Loop 구조에서 사용하지 않습니다.

이 문서는 과거 의사결정 이력입니다. 현재는 Source Sync와 Knowledge Processing/Publish가 독립 Run이며, Latest-Only로 supersede된 Work도 Processing 결과 집계에 포함합니다.

과거 D8

하나의 Sync Run이 Source + Publish를 함께 집계

2-Loop 채택 전의 모델입니다.

현재 Run 의미

Runcompletedpartialfailed
source_sync_runDiscovery 신뢰 + visible Project Source 책임 완료일부 Source progress + 일부 실패Discovery 불신뢰 또는 필요한 Source progress 없음
processing_run선택 Work가 published/정상 skip/superseded 등으로 정리되거나 Work 0일부 processing progress + 일부 실패/미완료의미 있는 processing progress 없이 실패

현재 Processing 집계

selected_count published_count failed_count superseded_count backlog_before backlog_after

superseded_count는 더 최신 Source 상태 때문에 과거 Work 처리를 건너뛴 수를 나타냅니다.
