Migration은 필수

기존 DB를 단순 재사용하는 것이 아니라 explicit migration으로 확장합니다. 현재 실제 목표는 Operational State Schema 개정 3이며 SQLite 기술 marker는 STATE_SCHEMA_VERSION = 3 / PRAGMA user_version = 3입니다.

왜 새 DB를 만들지 않나?

Source cursor, Watermark, Work backlog, Processing checkpoint는 모두 실행 Control Plane의 상태입니다. 기존 Collector Resume State와 같은 책임에 속하므로 하나의 State DB로 유지합니다.
