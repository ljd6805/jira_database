3. 운영 서비스 핵심

Loop A · Source Sync

Loop B · Latest-Only Processing

Source-ready이면서 최신인 Work만 OpenCode, Knowledge, BGE-M3, FAISS, Atomic Publish합니다.

T3 Atomic Boundary

Source Commit + Watermark + Ready Gate + supersede를 같은 State DB Transaction으로 확정합니다.

Explicit Migration

기존 collector.db는 일반 실행에서 자동 변경하지 않고 backup을 만든 뒤 명시적으로 승격합니다.

Structured Logging

work_item_superseded, stale_inflight_detected 등을 Jira 본문 없이 기록합니다.

Last-known-good MCP
