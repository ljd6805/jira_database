3. 운영 서비스 핵심

지속 Jira 업데이트

신규/수정 이슈와 댓글·관계·필드 변화가 다음 sync에 반영되어야 합니다.

Project 추가

접근 가능한 프로젝트 전체를 매 sync discovery하여 신규 프로젝트를 자동 편입하는 방향입니다.

증분 처리

unchanged는 reuse, new/changed만 Version→Knowledge→Embedding→FAISS로 전파합니다.

중앙 서비스

팀원은 Remote MCP를 사용하고 DB/FAISS/.env/BGE secret은 중앙 서버가 소유합니다.

중요: Remote MCP만 서버로 띄워도 Jira 갱신 파이프라인이 없으면 오래된 지식을 서비스하게 됩니다. 따라서 동기화와 서비스화를 함께 설계합니다.
