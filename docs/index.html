2. 전체를 한 줄씩만 보면

M0 Jira 사실을 안전하게 수집·정규화 M1 한 Issue의 모든 사실을 한 Package로 조립 M2 긴 사실에서 검색용 Knowledge 의미 카드를 추출 M3 Knowledge 생성·검증·Review·재생성 품질 Loop 설계 M4 그 Loop를 실제 Jira 30건으로 실전 검증 M5 실제 Knowledge 크기·Evidence·retry 분포를 측정 M6 측정값을 근거로 DB의 Entity/관계/ID를 설계 M7 그 설계를 실제 SQLite로 구현하고 무결성 검증 M8 Knowledge를 BGE-M3 1024차원 의미 vector로 변환 M9 질문과 의미가 가까운 Knowledge Top-3를 FAISS로 검색 M10 검색된 Knowledge에 실제 Jira Evidence를 붙여 MCP로 제공
기억하기 쉬운 축약 모으기(M0~M1) → 의미 만들기(M2~M4) → 재고 설계/저장(M5~M7) → 검색(M8~M9) → 근거를 붙여 Agent에 제공(M10).
