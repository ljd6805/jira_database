3. S4에서 지키려는 핵심

Watermark 선행 금지

source_committed와 Watermark advance는 같은 SQLite transaction에서 commit합니다.

짧은 Transaction

Jira API, 파일, LLM, Embedding을 하나의 긴 DB transaction으로 묶지 않습니다.

파일 먼저, State 나중

실제 durable Source/Stage 산출물이 준비된 뒤 cursor/status를 완료로 기록합니다.

Resume Cursor

후보 하나를 안전하게 끝낼 때 classification count와 cursor를 같은 transaction으로 이동합니다.

Publish 순서

실제 active Retrieval 전환이 먼저이며, 검증 후 State를 published로 기록합니다.

Fail Forward

Run이 partial/failed여도 이미 commit된 Project/Published 결과는 rollback하지 않습니다.
