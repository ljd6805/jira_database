4. 다음 단계 · M9 / M10

아직 계획 단계이며 구현되기 전까지 Baseline이나 추정 내용을 완료 사실처럼 읽지 않습니다.

M10 GATE

Evidence Builder + MCP

검색된 Knowledge를 Evidence source까지 round-trip하고 Agent가 사용할 MCP 도구로 노출하는 Functional MVP Gate입니다.
