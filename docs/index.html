3. 운영 서비스 핵심

Loop A · IMPLEMENTED

Jira Source를 project별 Watermark로 최신화하고 Source-ready latest backlog를 생산합니다.

Loop B Knowledge Automation · IMPLEMENTED

Python이 Work를 선택하고 opencode run --agent jira-knowledge-orchestrator를 호출합니다. Worker는 jira-knowledge-extraction Skill 사용을 요구합니다.

Real OpenCode · PENDING

사내 OpenCode 1.18.12에서 Orchestrator → Worker → Skill load → Validator → Reviewer를 실제 로그로 확인해야 합니다.

Scheduling · NOT IMPLEMENTED

현재는 사람이 runner를 시작하면 내부 Work 처리가 자동입니다. Scheduler/Daemon은 실제 처리량 측정 후 구현합니다.

Knowledge DB + Embedding · IMPLEMENTED

per-Work candidate Generation을 DB에 materialize하고 accepted Knowledge Item만 BGE-M3 staging합니다.

Atomic Publish · NEXT

FAISS와 Knowledge active state가 한 Published snapshot으로 일관되게 보이도록 publish 경계를 구현합니다.
