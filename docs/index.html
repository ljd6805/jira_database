3. 운영 서비스 핵심

지속 Jira 업데이트

신규/수정 이슈와 댓글·관계·필드 변화가 다음 Sync에 반영됩니다.

증분 처리

unchanged는 reuse, new/changed만 Version→Knowledge→Embedding→FAISS로 전파합니다.

지식 보존

Jira에서 Project/Issue가 사라져도 이미 축적된 Knowledge는 자동 삭제하지 않고 Retrieval에 계속 사용합니다.

안전한 Publish

새 Knowledge와 Retrieval index가 모두 준비되기 전에는 기존 Published 상태를 유지합니다.

중앙 서비스

팀원은 Remote MCP를 사용하고 DB/FAISS/.env/BGE secret은 중앙 서버가 소유합니다.
