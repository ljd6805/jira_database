3. M10 Real-run 숫자

tool_count: 2 MCP 기능 종류 2개 search_result_count: 3 Knowledge Top-3 Evidence_count: 6 실제 Jira 근거 총 6개 warning_count: 0 깨진 candidate 없음 path_leak_count: 0 내부 경로 노출 없음 issue_lookup_ok: true 실제 Issue 재조회 성공 failure_count: 0 실패 Gate 없음 M10_REAL_RUN = PASS

tool_count=2는 호출 횟수가 아니라 search_jira_knowledge, get_jira_issue 두 기능을 뜻합니다. evidence_count=6은 Issue 6개가 아니라 검색된 Knowledge 3개에 연결된 근거 조각 총 6개입니다.
