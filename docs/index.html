3. 이미 확정된 핵심

Delta-first

Jira updated는 후보 탐색, semantic_v2 hash가 실제 변경을 판정합니다.

Crash Safety

Source Commit과 Watermark는 같은 Transaction. 실제 durable 결과가 State보다 먼저입니다.

Knowledge 보존

Jira 삭제·비노출은 Knowledge 자동 삭제나 Retrieval 차단 이벤트가 아닙니다.

Publish Safety

새 Retrieval 상태가 완성될 때까지 기존 Published Knowledge를 제공합니다.

State DB Migration

기존 collector.db를 explicit versioned migration으로 확장합니다. Backup/validation/rollback이 필수입니다.

4 Domain Tables

sync_run / project_state / sync_project_run / sync_issue_change가 v1 baseline입니다.
