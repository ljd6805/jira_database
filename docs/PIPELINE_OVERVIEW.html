2. 흔들리면 안 되는 원칙

RAW = Source of Truth

뒤 계층은 앞 계층에서 다시 만들 수 있는 파생물이어야 합니다.

History ≠ Active Retrieval

DB는 이력을 보존하지만 검색 입력은 active generation의 accepted attempt에서 만든 snapshot만 사용합니다.

Identity 분리

Knowledge ID, Embedding ID, Retrieval Contract, FAISS position은 서로 다른 개념이며 섞지 않습니다.

RAW → ANALYSIS → KNOWLEDGE INPUT → KNOWLEDGE → DB → EMBEDDING → RETRIEVAL

jira_id → iv_ → kc_ → kg_ → ka_(attempt_no) → ki_ → ke_

Embedding Contract   ec_
Embedding Artifact   emb_
Retrieval Contract   rc_
FAISS Index Artifact fi_

FAISS position ≠ embedding_id ≠ knowledge_item_id
