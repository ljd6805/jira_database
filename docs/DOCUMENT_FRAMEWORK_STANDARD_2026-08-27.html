DOCUMENT UI FRAME · 개정 1 · DECIDED · 2026-08-31

문서의 내용은 늘어나도
문서의 틀은 흔들리지 않게

Documentation Hub와 모든 HTML 문서의 공통 탐색 규칙을 하나의 프레임으로 고정합니다. 여기서 개정 1은 문서 UI 틀의 번호이며 State DB, Knowledge DB, Sync Contract의 개정 번호와 관계없습니다.

버전 숫자 혼동 방지
예전 문서의 Document Framework v1, Document Shell v1, Hub Frame v1은 모두 문서 UI 프레임 개정 1을 뜻합니다. Operational State Schema 개정 3이나 Knowledge DB Schema 개정 1과 비교하는 숫자가 아닙니다. 자세한 규칙은 버전 표기 가이드를 따릅니다.

1. 이번에 고정한 것

Hub Frame · 개정 1

Hub는 5개 기본 영역과 공통 카드/색상/폭을 assets/hub-frame.css에서 관리합니다.

Document Shell · 개정 1

모든 일반 HTML 문서는 같은 CSS/JS shell을 포함합니다.

Navigation Contract

이전 문서 / 문서 Hub / 다음 문서가 항상 같은 위치와 모양으로 존재합니다.

2. 내비게이션 계약

버튼은 없어지지 않습니다.
첫 번째 문서라 이전 문서가 없거나 마지막 문서라 다음 문서가 없더라도 버튼 영역 자체는 유지하고 disabled 상태로 표시합니다.
버튼항상 존재?동작
← 이전 문서예Registry 기준 이전 문서. 없으면 disabled.
⌂ 문서 Hub예항상 docs/index.html로 복귀.
다음 문서 →예Registry 기준 다음 문서. 없으면 disabled.

긴 문서에서도 탐색이 끊기지 않도록 같은 세 버튼을 문서 상단과 하단에 모두 제공합니다.

3. 공통 버전 도움말

Document Shell은 문서 본문에서 v1/v2/v3, semantic_v2, schema_version 같은 표현을 감지하면 상단에 공통 버전 도움말을 표시합니다.

숫자만 비교하지 않기
→ 현재/과거 상태 확인
→ 무엇의 버전인지 확인
→ 같은 대상 안에서만 개정 번호 비교

Historical/Baseline 문서는 공통 Shell이 “과거 설계 보관본 · 현재 구현 기준 아님” 상태를 추가로 표시합니다.

3.5. 시각화와 설명은 함께 보존

시각화는 설명을 대체하지 않고 보강한다.
새 그림이나 더 좋은 레이아웃을 만들었다는 이유로 기존의 유효한 설명을 지우지 않습니다. 시각화는 빠른 이해를 돕고, 상세 설명은 검증과 복기를 담당합니다.
권장 읽기 구조

그림
→ 상세 설명
→ 관계/표
→ 쉬운 예시
→ Source of Truth

복잡하면 설명을 없애는 대신 diagram을 분리하거나 카드/표와 역할을 나눕니다. 내용 삭제/축약은 사용자가 명시적으로 삭제/축약을 요청했거나 오래되어 틀린 내용임이 확인된 경우에만 허용하며, 삭제 이유를 문서에 남깁니다.

6. 새 문서를 만드는 방법

1. docs/templates/STANDARD_DOCUMENT_TEMPLATE.html 복사
2. 제목 / 본문 / 목적에 맞는 시각 요소 작성
3. 기존 문서를 개선하는 경우 before/after 설명 coverage 확인
4. 그림 → 상세 설명 → 관계/표 → 쉬운 예시 → Source of Truth 구조 우선
5. 현재/과거 상태 + 대상 + 개정 번호 순서로 버전 표기
6. docs/index.html의 알맞은 영역에 HTML 링크 추가
7. python tools/docs/sync_document_shell.py --write
8. python tools/docs/sync_document_shell.py --check
9. pytest tests/test_document_shell_consistency.py
10. pytest tests/test_documentation_content_preservation_rule.py
11. 관련 문서 Gate까지 통과 후 commit

7. 기존 문서 처리

2026-08-27 migration에서 docs/index.html을 제외한 기존 HTML 전체를 Document Shell 대상으로 삼았습니다. 2026-08-31부터는 공통 버전 도움말도 같은 Shell에서 제공합니다. 과거 문서 본문은 이력 보존을 위해 무조건 다시 쓰지 않지만, 현재 문서처럼 오해될 수 있는 상태/버전 표현은 명확히 교정합니다. 현재 문서를 디자인 개선할 때도 기존의 유효한 설명을 임의로 제거하지 않습니다.

8. 변경이 필요할 때

문서 UI 프레임 개정 1을 바꾸는 것은 일반 문서 편집이 아닙니다.
Hub 기본 영역, 버튼 계약, Registry 방식, 공통 asset 경로, 버전 도움말 규칙을 바꾸려면 DOCUMENTATION_POLICY.html과 이 문서를 함께 갱신하고 회귀 테스트도 같이 수정합니다.
