3. Legacy M4 Attempt를 거짓 복원하지 않는다

Attempt 1 FAIL → Attempt row + Review / Finding → content_available = false Accepted Attempt N PASS → Attempt row + Review / Finding → Knowledge Item / Evidence → content_available = true → accepted_attempt_id → Generation active
M4에는 failed Attempt 당시 Knowledge body가 남지 않았습니다. M7은 존재하지 않는 본문을 추정해 채우지 않고 “콘텐츠 없음” 자체를 정확히 저장합니다.
