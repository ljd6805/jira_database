3. source_path / source_hash

Portable source_path

가능한 경로는 DATA ROOT 기준 상대경로로 바꿔 PC 설치 위치와 의미 데이터를 분리합니다.

Semantic source_hash

issue/comments/attachments/relationships/custom_fields의 의미 데이터만 canonical JSON + SHA-256으로 계산합니다. generated_at과 경로성 값은 제외합니다.

same semantic facts → same source_hash different facts → different source_hash 향후 source_hash 동일 → Knowledge 재추출 생략 가능

4. Manifest와 Snapshot 재생성

manifest.json은 단순 통계가 아니라 완료 표식입니다. 기존 manifest 삭제 → package 원자 저장 → stale package 삭제 → warnings 저장 → 마지막에 manifest 원자 저장 순서를 사용합니다.

중간 종료 시: 새 manifest가 남지 않습니다. append 방식이 아니라 현재 ANALYSIS로 현재 Knowledge Input snapshot 전체를 재생성해 유령 package가 섞이는 것을 막습니다.
