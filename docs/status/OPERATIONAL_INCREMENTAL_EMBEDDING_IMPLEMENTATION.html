1. 구현된 Embedding 범위

Generation 단위 Corpus

load_generation_embedding_corpus()가 accepted Knowledge Item을 deterministic 순서로 읽습니다.

Latest-only BGE-M3

OperationalEmbeddingWorker는 Source-ready/latest Work만 처리합니다.

Atomic staging artifact

corpus.jsonl, embeddings.jsonl을 임시 파일 후 atomic replace합니다.

Independent Processing Run

Embedding stage도 별도 processing_run으로 실행되며 Publish가 이어받도록 완료 후 Work를 pending으로 돌립니다.

2. 안전 순서

Knowledge checkpoint completed → Knowledge worker가 running Work를 pending으로 handoff → Incremental Knowledge DB candidate + accepted_attempt_id → latest / Source Ready 확인 → embedding_status = running → Generation corpus 생성 → BGE-M3 호출 → latest 재확인 → embeddings.jsonl atomic 저장 → latest 재확인 → embedding_status = completed → work_status = pending → Publish stage
핵심

Materializer는 running Work를 받지 않습니다. running은 processing worker가 아직 소유하고 있는 transient 상태이며, 정상 G2 종료 경계는 pending입니다.

4. 복구 방식

Helper 이름 정렬

Incremental이 현재 loader의 _insert_custom_field_catalog(), _insert_custom_field_value()를 사용하도록 수정했습니다.

Issue row 계약 정렬

analysis["issue"]를 현재 _upsert_issue(connection, row)에 전달하고 jira_id는 row에서 명시적으로 검증합니다.

Issue Version 계약 정렬

State/semantic hash로 이미 계산한 deterministic issue_version_id를 현재 _ensure_issue_version()에 전달합니다.

Legacy shim 금지

base loader에 과거 signature를 다시 추가하지 않았습니다. caller를 current contract에 맞춰 drift를 제거했습니다.

기존 data_smoke는 삭제하지 않습니다. G1/G2가 만든 Source Ready와 Knowledge checkpoint를 그대로 사용해 먼저 Incremental Materializer candidate를 생성하고, 그 candidate를 기존 tools/run_embedding_worker.py에 연결합니다.

9. 중요한 실행 경계 · Batch Materializer 사용 금지

G3에서는 tools/jira_knowledge/materialize_knowledge_db.py를 사용하지 않습니다.

이 도구는 Batch용 KnowledgeDbMaterializer.materialize_run()을 호출합니다. Batch loader의 final Review 처리 경로는 _publish_generation()까지 호출하여 Generation을 active로 전환할 수 있습니다. 그러나 현재 운영 G3의 계약은 candidate + accepted_attempt_id까지만 준비하고 Publish는 하지 않는 것입니다.

잘못된 G3 경로 materialize_knowledge_db.py → KnowledgeDbMaterializer.materialize_run() → _load_attempts() → _publish_generation() → active 가능 → G4 Publish 경계를 G3가 침범 올바른 G3 경로 IncrementalKnowledgeDbMaterializer.materialize_work(work_item_id) → candidate + accepted_attempt_id → 실제 BGE-M3 → embedding_status=completed → Generation은 candidate 유지 → G4에서만 Atomic Publish

@'
from pathlib import Path
import sqlite3

from jira_collector.state_store import StateStore
from jira_collector.knowledge_db.incremental import IncrementalKnowledgeDbMaterializer
from jira_collector.knowledge_db import connect_database, validate_accepted_evidence

DATA_ROOT = Path("data_smoke")
STATE_DB = DATA_ROOT / "state" / "collector.db"
KNOWLEDGE_DB = DATA_ROOT / "knowledge_db" / "jira_knowledge.sqlite3"

state = StateStore(STATE_DB)
with state.connect() as connection:
    rows = connection.execute(
        """
        SELECT work_item_id
        FROM sync_issue_change
        WHERE last_source_committed_run_id IS NOT NULL
          AND last_source_committed_run_id = last_observed_source_run_id
          AND work_status = 'pending'
          AND knowledge_status = 'completed'
          AND embedding_status = 'pending'
          AND superseded_by_work_item_id IS NULL
        ORDER BY last_source_committed_at, created_at, work_item_id
        LIMIT 2
        """
    ).fetchall()

if len(rows) != 1:
    raise SystemExit(f"G3 candidate Work는 정확히 1개여야 합니다. actual={len(rows)}")

work_item_id = str(rows[0]["work_item_id"])
materializer = IncrementalKnowledgeDbMaterializer(
    state,
    DATA_ROOT,
    KNOWLEDGE_DB,
    skill_version="0.9",
    runtime_version="0.9",
    model_profile="internal-opencode-knowledge-v1",
)
result = materializer.materialize_work(work_item_id)
print("G3_CANDIDATE = CREATED")
print("work_item_id =", result.work_item_id)
print("knowledge_generation_id =", result.knowledge_generation_id)
print("generation_state =", result.generation_state)
print("final_attempt_id =", result.final_attempt_id)
print("knowledge_item_count =", result.knowledge_item_count)
print("evidence_count =", result.evidence_count)

connection = connect_database(KNOWLEDGE_DB)
try:
    generation = connection.execute(
        """
        SELECT state, accepted_attempt_id
        FROM knowledge_generation
        WHERE knowledge_generation_id=?

        (result.knowledge_generation_id,),
    ).fetchone()
    problems = validate_accepted_evidence(connection)
finally:
    connection.close()

if generation is None:

if generation["state"] != "candidate":
    raise SystemExit(f"G3 FAIL: candidate가 아닙니다: {generation['state']}")
if not generation["accepted_attempt_id"]:
    raise SystemExit("G3 FAIL: accepted_attempt_id가 없습니다.")

    raise SystemExit(f"G3 FAIL: Evidence validation={problems}")

@'
from pathlib import Path
import json
import sqlite3

ROOT = Path("data_smoke")
state_db = ROOT / "state" / "collector.db"
knowledge_db = ROOT / "knowledge_db" / "jira_knowledge.sqlite3"

with sqlite3.connect(state_db) as connection:
    connection.row_factory = sqlite3.Row
    rows = connection.execute(
        """
        SELECT work_item_id, knowledge_generation_id,
               work_status, knowledge_status, embedding_status, publish_status
        FROM sync_issue_change
        WHERE knowledge_status='completed'
          AND embedding_status='completed'
          AND superseded_by_work_item_id IS NULL
        ORDER BY updated_at DESC
        LIMIT 2
        """
    ).fetchall()

if len(rows) != 1:
    raise SystemExit(f"G3 completed Work는 정확히 1개여야 합니다. actual={len(rows)}")
work = rows[0]
work_id = str(work["work_item_id"])
generation_id = str(work["knowledge_generation_id"])

if work["work_status"] != "pending":
    raise SystemExit(f"G3 FAIL: work_status={work['work_status']}")
if work["publish_status"] != "pending":
    raise SystemExit(f"G3 FAIL: publish_status={work['publish_status']}")

with sqlite3.connect(knowledge_db) as connection:
    connection.row_factory = sqlite3.Row
    generation = connection.execute(
        "SELECT state, accepted_attempt_id FROM knowledge_generation WHERE knowledge_generation_id=?",
        (generation_id,),
    ).fetchone()

if generation is None or generation["state"] != "candidate":
    raise SystemExit(f"G3 FAIL: generation state={None if generation is None else generation['state']}")

work_root = ROOT / "embedding" / "operational" / "work" / work_id
corpus_path = work_root / "corpus.jsonl"
embedding_path = work_root / "embeddings.jsonl"
if not corpus_path.is_file() or not embedding_path.is_file():
    raise SystemExit("G3 FAIL: corpus/embedding artifact가 없습니다.")

corpus = [json.loads(line) for line in corpus_path.read_text(encoding="utf-8").splitlines() if line.strip()]
embeddings = [json.loads(line) for line in embedding_path.read_text(encoding="utf-8").splitlines() if line.strip()]
if not corpus or len(corpus) != len(embeddings):
    raise SystemExit(f"G3 FAIL: row count corpus={len(corpus)}, embedding={len(embeddings)}")
for row in embeddings:
    if row.get("embedding_dimension") != 1024:
        raise SystemExit(f"G3 FAIL: embedding_dimension={row.get('embedding_dimension')}")
    if len(row.get("vector") or []) != 1024:
        raise SystemExit(f"G3 FAIL: vector length={len(row.get('vector') or [])}")
    if row.get("knowledge_generation_id") != generation_id:
        raise SystemExit("G3 FAIL: embedding artifact Generation identity mismatch")

print("G3_REAL_BGE_M3 = PASS")
print("work_item_id =", work_id)
print("knowledge_generation_id =", generation_id)
print("rows =", len(embeddings))
print("dimension = 1024")
print("generation_state = candidate")
print("work_status = pending")
print("publish_status = pending")
print("next = G4 Atomic Publish")
