5. 다시 뒤집지 않을 원칙

Source Loop ≠ Processing Loop

서로 독립 Scheduler/Run/실패 경계.

SOURCE_COMMITTED ≠ PUBLISHED

Source Commit은 Loop A, Publish는 Loop B.

Jira Lifecycle ≠ Knowledge Lifecycle

Jira 비노출/삭제가 Knowledge 삭제를 뜻하지 않음.

Last-known-good Retrieval

새 Publish 전까지 기존 Published Knowledge 제공.

Delta-first

5분 overlap + fixed upper + semantic_v2.

Fail Forward

성공 결과 보존, 실패한 Loop/Stage만 재시도.
