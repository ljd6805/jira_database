8. 다음 구현에서 가장 중요한 문제

Half-Publish를 막는 coherent publish boundary

Knowledge DB의 active Generation과 FAISS active artifact는 서로 다른 durability domain입니다. DB를 먼저 바꾸거나 FAISS를 먼저 바꾸면 짧은 순간이라도 서로 다른 세대를 볼 수 있습니다. 다음 구현은 이 문제를 active bundle/pointer 방식으로 먼저 해결해야 합니다.

절대 금지 Knowledge active = NEW FAISS active = OLD 또는 Knowledge active = OLD FAISS active = NEW 목표 하나의 Published bundle identity를 통해 Knowledge + FAISS + mapping + manifest가 항상 같은 snapshot으로 보이게 전환
