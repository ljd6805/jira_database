4. 특히 다시 뒤집으면 안 되는 원칙

Jira Source Lifecycle ≠ Knowledge Lifecycle

Jira에서 삭제되었다고 Knowledge/Vector를 자동 삭제하지 않습니다.

Source Commit ≠ Publish

새 Source를 확보해도 새 Retrieval이 완성될 때까지 기존 Published Knowledge를 제공합니다.

Delta-first

중복 후보는 허용하되 실제 new/changed만 비싼 downstream을 수행합니다.

Fail forward

성공한 독립 작업은 보존하고 실패한 Stage만 재시도합니다. 전역 rollback을 하지 않습니다.
