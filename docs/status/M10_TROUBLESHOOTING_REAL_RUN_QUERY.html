M10_REAL_RUN_QUERY
환경 변수가 비어 있습니다

M10 Real-run 검증기는 실제 검색 경로를 시험하기 위해 질문 1개가 필요합니다. 질문이 설정되지 않으면 BGE-M3 호출 전에 안전하게 중단합니다.

EXPECTED PRECONDITION · CODE ERROR 아님

무엇을 넣어야 하나?

파일럿 Jira 30건 안에 실제로 존재할 것으로 기대하는 업무 질문을 넣습니다. 예를 들어 특정 문제의 원인, 조치, 결과처럼 이미 수집된 Jira 내용과 연결될 가능성이 높은 질문이 좋습니다. 공개 문서에는 실제 질문 내용을 기록하지 않습니다.

현재 테스트 환경

Windows PowerShell에서 설정하기

현재 Windows에서 테스트 중이라면 Linux의 read/export/unset 대신 PowerShell의 Read-Host와 $env: 문법을 사용합니다.

$env:M10_REAL_RUN_QUERY = Read-Host "M10 test query" if ($env:M10_REAL_RUN_QUERY) { Write-Host "M10 query: SET" } else { Write-Host "M10 query: EMPTY" } python tools/jira_knowledge/validate_m10_real_run.py Remove-Item Env:M10_REAL_RUN_QUERY
권장: 질문 문자열을 명령줄에 직접 적지 않고 Read-Host로 입력하면 PowerShell history에 질문 내용 자체를 남기지 않을 수 있습니다.

PowerShell에서 직접 설정해도 되는 경우

민감하지 않은 테스트 문자열이라면 아래처럼 직접 설정할 수도 있습니다.

$env:M10_REAL_RUN_QUERY = "여기에 실제 검색 질문을 입력" python tools/jira_knowledge/validate_m10_real_run.py Remove-Item Env:M10_REAL_RUN_QUERY
주의: 이 방식은 명령 자체가 PowerShell history에 남을 수 있으므로 실제 업무 문장이라면 Read-Host 방식을 권장합니다.

Windows CMD를 쓰는 경우

set /p M10_REAL_RUN_QUERY=M10 test query: python tools\jira_knowledge\validate_m10_real_run.py set M10_REAL_RUN_QUERY=

현재 터미널이 PowerShell이라면 CMD 문법보다 위의 PowerShell 방법을 사용합니다.

나중에 Linux로 포팅하면

read -r -p "M10 test query: " M10_REAL_RUN_QUERY export M10_REAL_RUN_QUERY python3 tools/jira_knowledge/validate_m10_real_run.py unset M10_REAL_RUN_QUERY

질문 선택 기준

✓ 파일럿 Jira 안에 관련 내용이 있을 가능성이 높다
✓ 너무 광범위하지 않다
✓ 원인/조치/결과처럼 Knowledge로 추출됐을 법하다
✓ 실제 Issue Key나 원문을 공개 문서에 남기지 않는다
