M10 TROUBLESHOOTING · 2026-08-27

M10_REAL_RUN_QUERY
환경 변수가 비어 있습니다

M10 Real-run 검증기는 실제 검색 경로를 시험하기 위해 질문 1개가 필요합니다. 질문이 설정되지 않으면 BGE-M3 호출 전에 안전하게 중단합니다.

EXPECTED PRECONDITION · CODE ERROR 아님

무엇을 넣어야 하나?

파일럿 Jira 30건 안에 실제로 존재할 것으로 기대하는 업무 질문을 넣습니다. 예를 들어 특정 문제의 원인, 조치, 결과처럼 이미 수집된 Jira 내용과 연결될 가능성이 높은 질문이 좋습니다. 공개 문서에는 실제 질문 내용을 기록하지 않습니다.

권장 입력 방법

실제 Jira 업무 내용이 shell history에 남지 않도록 read로 입력한 뒤 export하는 방법을 권장합니다.

read -r -p "M10 test query: " M10_REAL_RUN_QUERY export M10_REAL_RUN_QUERY python3 tools/jira_knowledge/validate_m10_real_run.py unset M10_REAL_RUN_QUERY

화면에도 질문을 보이지 않게 하려면 read -s를 사용할 수 있습니다.

read -s -r -p "M10 test query: " M10_REAL_RUN_QUERY; echo export M10_REAL_RUN_QUERY python3 tools/jira_knowledge/validate_m10_real_run.py unset M10_REAL_RUN_QUERY

단순 확인용

민감하지 않은 테스트 문자열이라면 아래처럼 직접 설정해도 됩니다.

export M10_REAL_RUN_QUERY='여기에 실제 검색 질문을 입력' python3 tools/jira_knowledge/validate_m10_real_run.py

설정 확인

질문 자체를 출력하지 않고 설정 여부만 확인합니다.

test -n "$M10_REAL_RUN_QUERY" && echo "M10 query: SET" || echo "M10 query: EMPTY"

질문 선택 기준

✓ 파일럿 Jira 안에 관련 내용이 있을 가능성이 높다
✓ 너무 광범위하지 않다
✓ 원인/조치/결과처럼 Knowledge로 추출됐을 법하다
✓ 실제 Issue Key나 원문을 공개 문서에 남기지 않는다
