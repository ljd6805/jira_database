T01 · VS Code SQLite extension 오류

증상

no such column: "table" WHERE (type="table" OR type="view")

판단

M7 SQLite integrity/FK Gate는 이미 PASS였습니다. 오류는 DB 내용이 아니라 오래된 Viewer extension이 schema 목록을 읽으며 실행한 query에서 발생했습니다.

해결

legacy vscode-sqlite 대신 read-only 중심의 다른 SQLite Viewer로 교체해 DB 내용을 확인했습니다.

재발 방지

Viewer 오류를 DB corruption으로 바로 해석하지 않습니다. Python sqlite3와 PRAGMA integrity_check를 우선 기준으로 봅니다.

T02 · python-dotenv parse error

증상

python-dotenv could not parse statement starting at line ...

원인

여러 줄 custom header JSON이 하나의 환경변수 값으로 묶이지 않아 각 JSON 줄이 별도 KEY=VALUE 문장처럼 해석됐습니다.

해결

BGE_M3_HEADERS_JSON 전체를 하나의 dotenv value로 작성했습니다. 한 줄 JSON 또는 quote로 감싼 multi-line JSON을 사용할 수 있습니다.

핵심

한 줄이어야 한다 X JSON 전체가 하나의 환경변수 값이어야 한다 O

T03 · JSONDecodeError와 Python 표현식

증상

JSONDecodeError: Expecting value BGE_M3_HEADERS_JSON은 JSON object여야 합니다.

원인

header 값에 str(uuid.uuid4()) 같은 Python 실행식이 들어 있었습니다. 이는 JSON literal이 아닙니다.

해결

static custom header만 JSON에 남겼습니다. 동적으로 계산해야 하는 header는 static JSON에서 제외했습니다.

재발 방지

runtime 계산값이 정말 필요하다고 확인될 때만 code-level dynamic header provider로 분리합니다.

T04 · 사내 custom header 지원

상황

사내 embedding API는 표준 Bearer token만 쓰지 않고 custom header를 사용합니다.

구현

BGE_M3_ENDPOINT BGE_M3_API_KEY optional BGE_M3_HEADERS_JSON optional

보안/Identity 원칙

custom header는 HTTP runtime에만 사용합니다. header 이름/값은 ec_/emb_ identity, vector artifact, stdout, public docs에 넣지 않습니다.

설정 결과

endpoint: True api_key: False custom_headers: 6 model: BAAI/bge-m3 dimension: 1024

T05 · HTTP 404

증상

Embedding API HTTP 404; retry하지 않습니다.

진단

서버까지는 도달했지만 embeddings route가 아닌 경로를 사용한 것으로 판단했습니다. 404는 transient 장애가 아니므로 retry 대상이 아닙니다.

해결

BGE_M3_ENDPOINT를 실제 사내 OpenAI-compatible embeddings 전체 URL로 수정했습니다.

상태코드 기준

404 → endpoint/path 401 / 403 → auth/header 400 / 422 → request contract 429 / 5xx → transient retry 200 → schema/dimension 검증

T06 · corpus_rows 28 전달 오류

상황

대화 중 복사/붙여넣기로 28이 전달됐지만 실제 실행 결과는 285였습니다.

조치

프로젝트 결함으로 기록하지 않고, CLI의 --expected-count 285 Gate를 유지했습니다.

교훈

사람이 전달한 숫자와 deterministic 실행 Gate를 분리합니다. count mismatch는 CLI가 종료코드로 강제합니다.
