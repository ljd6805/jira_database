5. QA 중 발견한 Source Ready Race

2-Loop에서 후보 Issue를 처리하는 T2 시점에 Work Item row를 먼저 만들 수 있는데, Project 전체 Source window가 아직 Commit되기 전에 Loop B가 그 row를 소비하는 race가 발견됐습니다.

잘못된 가능성 T2: Work Item row 존재 → Loop B claim → 이후 같은 Project의 다른 Source 후보 실패 → Project Source Commit 실패 해결 Loop B eligible iff last_source_committed_run_id IS NOT NULL AND last_source_committed_run_id = last_observed_source_run_id

T3 Project Commit에서 source_committed + Watermark + Work Item Source Ready Gate를 같은 State DB Transaction으로 확정하도록 Contract/Schema/DDL을 보강했습니다.
