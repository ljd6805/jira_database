3. Identity

Knowledge identity jira_id → iv_ → kc_ → kg_ → ka_(attempt_no) → ki_ → ke_ Embedding identity ki_ + text hash + ec_ → emb_ ec_ = model + model_profile + text_profile + dimension + contract version Endpoint / API key / custom header / FAISS position ≠ embedding identity

4. BGE-M3 Contract

Request

{model, input[]} OpenAI-compatible.

Mapping

data[].index로 request input 위치 복원.

Validation

누락/중복 index 차단, 모든 vector=1024-dim.

Runtime secret 분리 실제 endpoint/API key/custom header는 .env의 BGE_M3_ENDPOINT, BGE_M3_API_KEY, BGE_M3_HEADERS_JSON으로만 입력합니다. 실제 header 이름/값은 문서나 artifact에 남기지 않습니다.

5. Custom Header

# Bearer 인증을 쓰지 않는 경우 API key는 비워도 됨 BGE_M3_API_KEY= # 여러 custom header를 JSON object 하나로 전달 BGE_M3_HEADERS_JSON='{"X-Custom-Header-1":"value1","X-Custom-Header-2":"value2"}'

Header는 HTTP request에만 사용되며 ec_/emb_ identity, stdout, embedding JSONL에 포함하지 않습니다.
