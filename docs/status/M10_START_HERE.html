Resolver Contract

MCP Tool Surface

6. M10 구현에서 추가한 안전장치

Stale Candidate 차단

ki_가 지금도 active + accepted + content_available인지 DB에서 다시 검사합니다.

Candidate 격리

Top-3 중 하나가 깨져도 정상 후보는 반환하고 깨진 후보만 warning으로 격리합니다.

DB Read-only

SQLite를 mode=ro + PRAGMA query_only=ON으로 열어 쓰기를 DB 레벨에서 차단합니다.

Path 미노출

source_path / source_page는 MCP structured response에 포함하지 않습니다.
