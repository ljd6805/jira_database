2. 왜 지금 IndexFlatIP인가?

Exact

285개 전부를 비교해 approximate recall 손실이 없습니다.

No training

IVF centroid 학습 없이 바로 만들 수 있습니다.

Test oracle

향후 HNSW/IVF의 recall을 비교할 정확한 기준점입니다.

Flat은 영구 구조가 아닙니다

데이터가 커지면 p95 latency·RAM·QPS·rebuild 비용을 측정하고 HNSW/IVF를 benchmark합니다. 전환은 고정 vector 개수가 아니라 측정값으로 결정합니다.

3. Cosine은 어떻게 계산하나?

M8 vector → float32 copy → L2 normalize → IndexFlatIP.add() 사용자 질문 → 같은 BGE-M3 1024-d → L2 normalize → IndexFlatIP.search() normalized inner product = cosine similarity
원본 보존

M8 embedding JSONL 자체는 수정하지 않습니다. FAISS에 넣을 복사본만 normalize합니다.

7. 구현된 안전장치

M8 source 재검증

현재 corpus+embedding이 실제로 M8 Gate를 통과하는지 build 직전에 다시 확인합니다.

Hash 검증

manifest의 index/mapping SHA-256과 실제 파일이 다르면 searcher가 열지 않습니다.

Identity 재계산

rc_와 fi_를 manifest에서 다시 계산해 계약 drift를 차단합니다.

Normalization 검증

FAISS 안의 모든 vector norm이 1인지 검사합니다.

Mapping round-trip

Real Gate에서는 mapping이 M8 source row와 정확히 대응하는지 다시 비교합니다.

Query vector-space guard

BGE-M3 model/profile/dimension이 manifest와 다르면 API 호출 전에 실패합니다.
