5. 정식 서비스는 Delta-first

변경 없음

아무 작업도 하지 않고 기존 embedding/index를 유지합니다.

추가/변경

필요한 vector만 생성 또는 재사용하고 index entry만 add/replace합니다.

삭제/비활성

검색 entry를 remove 또는 tombstone 처리합니다.

Full rebuild

maintenance, integrity 검증, migration, recovery 용도로 남깁니다.

운영형 exact 후보

Incremental mutation에서는 sequential position 이동 문제를 피하기 위해 IndexIDMap2(IndexFlatIP) + stable int64 vector_id 같은 explicit-ID 구조를 후속 production-hardening에서 검토합니다.
