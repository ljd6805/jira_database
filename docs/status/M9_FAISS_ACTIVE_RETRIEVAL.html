3. 왜 IndexFlatIP인가?

Exact

285개 전부를 비교해 approximate recall 손실이 없습니다.

No training

IVF centroid 학습 없이 바로 만들 수 있습니다.

Test oracle

향후 HNSW/IVF recall을 비교할 기준점입니다.

Flat은 영구 구조가 아닙니다

데이터가 커지면 p95 latency·RAM·QPS·rebuild 비용을 측정하고 ANN을 benchmark합니다.

4. Cosine / Top-k baseline

M8 vector → float32 copy → L2 normalize → IndexFlatIP.add() query → same BGE-M3 → L2 normalize → IndexFlatIP.search() normalized inner product = cosine similarity Top-k = 3 Threshold = none Reranker = none

7. Rebuild에서 무엇이 같아야 하나?

필수 동일 retrieval_contract_hash · rc_ faiss_index_id · fi_ source_embedding_artifact_sha256 mapping_sha256 보조 관찰 faiss_binary_sha256

rc_, fi_, source SHA, canonical mapping SHA가 logical reproducibility의 핵심입니다. FAISS binary SHA는 같은 환경에서는 동일하면 좋지만 library/platform serialization 차이를 고려해 절대 Gate로 두지 않습니다.
