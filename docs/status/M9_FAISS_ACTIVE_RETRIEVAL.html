두 사례 모두 Rank 1/2는 유효했지만 Rank 3에는 noise가 있었습니다. 특히 점수가 서로 가까워도 의미 품질 차이가 날 수 있어 global cosine threshold/reranker를 근거 없이 추가하지 않았습니다.

쉽게 말하면 검색 점수는 “정답 확률”이 아닙니다. 같은 동네에 있는 문서를 찾아주는 거리값에 가깝습니다. 그래서 실제 근거와 함께 봐야 합니다.
