M10 TROUBLESHOOTING · 2026-08-27

ModuleNotFoundError:
No module named 'mcp'

M10 Real-run 실행 시 현재 Python 환경에 MCP Python SDK가 설치되지 않았을 때 발생하는 환경 오류입니다.

ENVIRONMENT ISSUE · CODE CONTRACT UNCHANGED

원인

현재 프로젝트의 pyproject.toml에는 mcp>=2.0,<3.0이 dependency로 정의되어 있습니다. 따라서 로컬 checkout이 오래됐거나, 최신 checkout 이후 현재 Python 환경에서 프로젝트 dependency를 다시 설치하지 않은 경우가 가장 유력합니다.

권장 복구 순서

cd jira_database git pull python3 --version python3 -m pip install -e '.[dev]' python3 -c "import mcp; print('mcp OK:', mcp.__file__)" python3 tools/jira_knowledge/validate_m10_real_run.py

프로젝트는 Python 3.11 이상을 요구합니다. pip 단독 명령보다 python3 -m pip를 사용해 실행 interpreter와 설치 interpreter를 일치시킵니다.

그래도 실패하면

which python3 python3 -m pip --version python3 -m pip show mcp python3 -c "import sys; print(sys.executable); print(sys.path)"

pip show mcp가 성공하는데 import가 실패하면 서로 다른 Python/virtualenv를 사용 중일 가능성이 높습니다.
