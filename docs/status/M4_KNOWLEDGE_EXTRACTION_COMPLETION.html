3. 실행 중 발견한 두 문제

.gitignore 때문에 다건 Glob 실패

OpenCode/ripgrep 탐색도 data/ ignore를 따랐습니다. root .ignore에서 knowledge_input / knowledge만 탐색 허용하고 Git 보안 경계는 유지했습니다.

LLM 최종 집계 불일치

Knowledge 품질 문제가 아니라 단순 산술을 LLM에게 맡긴 구조 문제였습니다. summarize_knowledge_run.py로 집계 책임을 deterministic code에 이동했습니다.

4. Human Validation

자동 Reviewer PASS만으로 종료하지 않고 대표 5건을 사람이 Knowledge Input과 최종 Knowledge로 직접 대조했습니다.

✓ 사실 왜곡 없음
✓ 과도한 인과 확정 없음
✓ 중요한 정보 누락 문제 없음
✓ Evidence 추적 가능
✓ 분류상 검색 의미 유지
✓ 5 / 5 검토 완료
중요: 선택 배열이 비어 있는 것 자체는 품질 오류가 아닙니다. 전체 Knowledge가 원문의 검색 의미를 보존하고 Evidence로 추적 가능한지가 기준입니다.
