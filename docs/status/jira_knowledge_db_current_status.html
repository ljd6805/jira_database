왜 running을 허용하지 않았나?

Knowledge 완료 직후 work_status='running'은 worker가 아직 Work를 소유한 transient 상태입니다. 실제 G2 종료 시 _release_after_knowledge()가 이를 pending으로 돌립니다. Incremental Materializer가 running까지 허용하면 다른 processing run이 소유한 Work를 건드릴 수 있으므로 production guard를 느슨하게 만들지 않았습니다.
