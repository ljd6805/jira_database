M8 · 현재 작업

M8은 Retrieval이 아니라 embedding corpus를 제대로 만드는 단계입니다.

1. Embedding Unit

Knowledge Item 자체를 기본 unit 후보로 검토하고 어떤 metadata를 함께 가져갈지 결정합니다.

2. Chunk Policy

모든 Item을 무조건 chunk하지 않고 길이·맥락·검색 가치에 따라 필요 조건을 정의합니다.

3. BGE-M3

OpenAI-compatible API, batch 최대 64, dense 1024-dim 계약을 기반으로 embedding을 생성·검증합니다.

경계 FAISS index와 Top-k Retrieval은 M9 책임입니다.
