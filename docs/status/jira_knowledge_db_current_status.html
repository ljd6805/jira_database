5. Troubleshooting에서 얻은 기준

Viewer 오류 ≠ DB 오류

SQLite integrity와 Viewer extension 오류를 분리합니다.

.env JSON

한 줄 강제가 아니라 JSON 전체가 하나의 dotenv value여야 합니다.

Custom headers

HTTP runtime에만 사용하고 ec_/emb_/artifact/public docs에는 secret 값을 넣지 않습니다.

HTTP 404

retry보다 endpoint/path를 먼저 확인합니다. 실제 route 수정 후 smoke PASS했습니다.
