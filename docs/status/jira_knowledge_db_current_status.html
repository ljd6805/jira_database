기존 Embedding 자동 테스트는 준비된 Knowledge DB와 fake OpenAI-compatible embedding client를 사용해 Embedding Worker 자체를 검증했습니다. 반면 실제 G3 앞단인 IncrementalKnowledgeDbMaterializer를 import하고 현재 loader.py와 end-to-end로 연결하는 회귀 테스트가 없었습니다. 따라서 Embedding Worker CI PASS와 Real G3 준비 경로 PASS는 같은 의미가 아니었습니다.
