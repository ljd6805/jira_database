4. M9-02 · 구현된 안전장치

M8 source 재검증

build 시작 시 corpus + embedding의 M8 integrity Gate를 다시 실행합니다.

Canonical order

source JSONL 순서와 무관하게 embedding_id ascending으로 index/mapping을 만듭니다.

Manifest-last publish

index/mapping을 검증한 뒤 manifest를 마지막에 publish해 완료 marker로 사용합니다.

Runtime reject

manifest SHA/mapping/normalization이 깨지면 검색기가 artifact를 열지 않습니다.

Query contract

현재 BGE-M3 model/profile/dimension이 index source와 다르면 API 호출 전에 차단합니다.

ANN 확장 경로

향후 latency/RAM/QPS/recall@k를 측정해 HNSW/IVF로 교체할 수 있습니다.
