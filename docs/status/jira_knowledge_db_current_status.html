Deterministic ID Ladder

“generation 회차까지 ID가 남는가?”에 대한 현재 authoritative 계약입니다.

jira_id ↓ iv_ = H(jira_id, source_hash) kc_ = H(knowledge_schema_version, skill_version, runtime_version, model_profile) kg_ = H(iv_, kc_) ↓ ka_ = H(kg_, attempt_no) ← 1차/2차/3차 회차 ID ↓ ki_ = H(ka_, category, ordinal) ↓ ke_ = H(ki_, ordinal, exact evidence_ref)
중요 같은 Version + 같은 Contract는 같은 kg_ lineage를 재사용합니다. 재시도/재생성 회차는 knowledge_attempt_id(ka_)와 attempt_no로 분리됩니다.
