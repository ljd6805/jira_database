3. Latest-Only 정책

Source History V1 → V2 → V3 → V4 모두 보존 Knowledge Processing V2 pending → superseded V3 pending → superseded V4 latest → process

이미 OpenCode가 구버전을 처리 중이면 호출을 강제 취소하지 않되, 응답 후 최신성을 다시 확인해 구버전이면 저장/Embedding/Publish를 중단합니다.

5. Loop B Claim Gate
