4. Loop B Knowledge 안전 규칙

Staging first

OpenCode가 쓴 파일은 바로 공식 Knowledge가 아닙니다. staging에 둔 뒤 검증을 통과해야 canonical로 승격합니다.

Latest after OpenCode

OpenCode가 느린 동안 더 최신 Source가 들어오면 구버전 결과는 canonical Knowledge로 승격하지 않습니다.

Artifact first, State second

실제 Knowledge/Review 파일을 durable하게 만든 뒤에만 knowledge_status=completed를 기록합니다.

Generation identity

model_profile을 명시적으로 받아 iv_ + Knowledge Contract → kg_를 결정합니다.

5. Source History / Latest-Only

Source History A → B → C → D 모두 보존 AI Processing B pending/running → newer Source로 superseded 가능 C pending → superseded D latest + Source-ready → OpenCode 처리

중간 Version은 삭제하지 않습니다. 지식화 대상에서 제외된 이유는 State/structured log로 추적합니다.

6. semantic_v2

Jira updated는 후보 신호이지 semantic identity가 아닙니다.

Issue/Comment updated_at, 경로, 실행 범위 파생값은 hash에서 제외하고 실제 업무 의미 데이터는 hash에 유지합니다.
