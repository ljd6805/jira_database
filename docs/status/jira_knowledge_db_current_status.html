4. Smoke 중 실제로 발견하고 고친 운영 문제

① python-dotenv stdin 자동탐색 문제 → .env 경로 명시 ② LLM 장애 후 Work 재시도 → 정상 failed backlog 확인 ③ Worker 비정상 종료 → work_status / knowledge_status = running 고착 발견 → stale in-flight recovery 구현 ④ headless OpenCode model 불명확 → model_profile과 opencode_model 분리 → codemate/CodeLLMPro 명시 ⑤ CodeLLMPro의 불필요한 Bash workspace preflight → permission을 풀지 않고 Agent tool discipline 강화 ⑥ data_smoke가 OpenCode Glob에서 보이지 않음 → .ignore에 data_smoke/knowledge_input, data_smoke/knowledge만 선택적으로 재노출 → Per-Work Orchestrator의 input rediscovery 제거

이 문제들은 단순 테스트 편의 수정이 아니라 정식 운영 전에 필요한 복구성·재현성·보안 경계를 실제 Smoke에서 검증한 결과입니다.
