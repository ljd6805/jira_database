3. 가장 중요한 운영 원칙

Delta-first

변경 후보만 다시 읽고 semantic hash로 실제 변경만 downstream에 전달합니다.

Knowledge 보존

Jira Project/Issue 삭제·비노출은 Knowledge 삭제 이벤트가 아닙니다. 기존 Retrieval을 유지합니다.

실패 복구

완료 Stage는 재사용하고 실패 Stage부터 Resume합니다.

안전한 Publish

새 Published 상태가 완성될 때까지 기존 Published Knowledge를 계속 제공합니다.
