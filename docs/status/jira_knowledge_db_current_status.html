3. Source Ready Gate

Work Item row 존재 ≠ Processing 가능
Loop B eligible iff last_source_committed_run_id IS NOT NULL AND last_source_committed_run_id = last_observed_source_run_id

Project 전체 Source window가 Commit된 관찰만 Loop B가 처리합니다.

T2 Candidate → Source file durable → Work row / last_observed / cursor commit → gate closed T3 Project Source Commit · SAME transaction → source_committed → committed_watermark = upper → last_source_committed_run_id = current → gate open
