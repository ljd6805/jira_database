4. Tool 2개는 정확히 무엇인가?

1) search_jira_knowledge

사용자 질문을 BGE-M3로 vector화하고 FAISS Top-3 Knowledge를 찾은 뒤, 각 Knowledge의 Evidence를 SQLite에서 복원해 구조화된 Package로 반환합니다.

2) get_jira_issue

검색된 Knowledge가 나온 실제 Jira Issue의 active snapshot을 직접 조회합니다. Agent가 검색 결과의 넓은 문맥을 더 보고 싶을 때 사용할 수 있습니다.

tool_count=2의 뜻

“MCP 호출 횟수 2회”가 아니라 “MCP가 공개하는 기능 종류가 정확히 2개”라는 뜻입니다.

5. Evidence 6개는 무엇인가?

Knowledge는 앞 단계에서 Jira 사실을 압축한 검색용 의미 문장입니다. M10은 그 문장을 믿을 수 있도록 실제 Jira 원문 근거를 다시 붙입니다.

Knowledge A ─┐ Knowledge B ─┼─→ 실제 Jira Evidence 합계 = 6 Knowledge C ─┘ Evidence 종류 summary / description / comment / attachment / relationship / custom_field

예를 들어 후보별로 2개 + 3개 + 1개라면 합계가 6이 될 수 있습니다. 하지만 이번 validator 출력은 안전한 aggregate만 남기므로 실제 후보별 분배는 기록하지 않습니다.
