2. 각 숫자의 뜻

항목뜻
tool_count: 2MCP가 공개하는 기능 종류가 정확히 2개라는 뜻입니다. search_jira_knowledge와 get_jira_issue이며, 호출 횟수가 2라는 뜻은 아닙니다.
search_result_count: 3M9 계약의 Top-3에 따라 질문과 가까운 Knowledge 후보 3개를 찾았다는 뜻입니다.
evidence_count: 6검색된 Knowledge 3개를 뒷받침하는 실제 Jira Evidence가 총 6개 복원됐다는 뜻입니다. Issue 6개라는 뜻이 아닙니다.
warning_count: 0stale/missing/invalid ref 같은 후보 무결성 경고가 없었습니다.
path_leak_count: 0내부 source_path/source_page가 MCP 외부 payload에 노출되지 않았습니다.
issue_lookup_ok: true검색 결과에서 실제 active Issue snapshot으로 다시 연결해 get_jira_issue가 성공했습니다.
failure_count: 0Completion Gate에서 실패한 검사가 하나도 없었습니다.

FAISS = Jira 원문 검색기가 아님 = Knowledge vector 검색기 질문 → BGE-M3 → FAISS ↓ Top-3 ki_ ↓ SQLite ke_ ↓ 실제 Jira Evidence source
