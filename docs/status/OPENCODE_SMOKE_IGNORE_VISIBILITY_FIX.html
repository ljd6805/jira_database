파일은 있는데 OpenCode에서는 “0 matches”

Linux Real Smoke에서 data_smoke/knowledge_input/.../AI5-2.json이 실제 파일시스템에는 존재하지만 OpenCode의 Glob 탐색에서는 보이지 않았던 문제를 기록합니다.

1. 실제 증상

Glob "data_smoke/knowledge_input/.../issues/AI5-2.json" 0 matches
Glob "data_smoke/knowledge_input/**" 0 matches
Glob "data_smoke/**" 0 matches

find ... data_smoke ...
→ bash permission deny

INPUT_ERROR AI5-2
중요

이 로그만 보면 파일이 없는 것처럼 보이지만, Python Source/Knowledge Worker가 사용한 실제 경로에는 파일이 존재했습니다. 문제는 파일 생성이 아니라 OpenCode 탐색 visibility였습니다.

2. 원인

.gitignore ├─ data/ └─ data_smoke/ ↓ Git에는 둘 다 넣지 않음 ↓ OpenCode/ripgrep 탐색도 ignore 영향을 받음 기존 .ignore └─ data/knowledge_input + data/knowledge만 다시 노출 빠진 것 └─ data_smoke/knowledge_input + data_smoke/knowledge

과거 M4 파일럿에서도 data/가 같은 이유로 Glob에서 보이지 않았고, root .ignore로 Knowledge 경로만 다시 열어 해결했습니다. Smoke root를 새로 추가하면서 동일한 visibility 계약을 확장하지 않은 것이 재발 원인입니다.

3. 수정된 .ignore 계약

# Formal / normal data root
!data/
data/*
!data/knowledge_input/
!data/knowledge_input/**
!data/knowledge/
!data/knowledge/**

# Isolated smoke data root
!data_smoke/
data_smoke/*
!data_smoke/knowledge_input/
!data_smoke/knowledge_input/**
!data_smoke/knowledge/
!data_smoke/knowledge/**

.gitignore의 data/, data_smoke/ 제외는 그대로 유지합니다. 즉 Git에는 올리지 않지만 OpenCode에는 필요한 Knowledge 경로만 보이게 합니다.

4. 왜 data_smoke 전체를 열지 않았나?

경로OpenCode Knowledge Agent에 필요?정책
data_smoke/raw아니오계속 숨김
data_smoke/analysis아니오계속 숨김
data_smoke/state아니오계속 숨김
data_smoke/knowledge_input예노출

Local-only 경계를 유지하면서 필요한 최소 경로만 노출하는 원칙입니다.

5. Per-Work Orchestrator도 함께 단순화

Python runner → 이미 정확한 INPUT/OUTPUT/REVIEW 경로 계산 → 디렉터리도 미리 생성 Orchestrator 이전: exact path를 다시 Glob/List로 탐색 현재: 전달받은 exact path를 authoritative로 사용 → workspace preflight 없음 → Glob/List 재탐색 없음 → Bash 없음 → Worker에 exact path 바로 전달 Worker → exact path를 직접 read → 읽기 실패 시에만 INPUT_ERROR

Per-Work 모드에서는 탐색 자체가 불필요합니다. Python이 이미 Work와 경로를 결정했기 때문에 Orchestrator는 다시 “찾는” 일을 하지 않습니다.

6. 재발 방지 테스트

tests/test_opencode_ignore_contract.py를 추가했습니다. data/와 data_smoke/의 Knowledge 경로가 모두 .ignore에서 노출되고, 동시에 두 runtime root가 .gitignore에는 계속 남아 있는지 검사합니다.

7. 운영 체크리스트

새 runtime data root를 추가한다 예: data_smoke / data_test / data_stage ↓ .gitignore 추가 ↓ OpenCode가 읽어야 하는가? ├─ NO → 끝 └─ YES ↓ .ignore에 최소 경로만 예외 노출 ↓ CI contract test 추가 ↓ Agent는 가능하면 exact path 사용
